# A Hike Through Time
Come meet Robin, and their dog Sam. Explore the forest around Great Creek and take A Hike Through Time! This game was made at the University of Alberta by TWCA (Team Without a Cool Acronym). Read the walkthough if you get lost, or learn about how the game was made. Feel free to report any issues on Github. All voice acting clips can be downloaded [here](https://drive.google.com/drive/folders/19SdCdiADcRM2bpm-FP-Sr87-Q-dPIrcR?usp=sha...).

## Running the game
#### In the web
1. The game can be played on itch.io [here](https://amuniversity.itch.io/a-hike-through-time).

#### In the unity editor
1. Download the repo
2. Add the "src" directory into Unity Hub
3. Open the game using Unity 2022.3.62f3
4. Open one of the scenes in Assets/Scenes, by default the game opens to Assets/Scenes/IntroScene.

## Controls
- Walk: WASD or click
- Collect item: click
- Place item: click to select item, then click to select location
